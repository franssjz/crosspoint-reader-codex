# Changelog

This changelog starts at `1.2.0.24`, the point where CPR-vCodex began tracking release changes in this file.

> Additional `1.5.0.20` sync: SD-font page bitmaps now use fragmentation-resistant 4 KiB chunks, and the font tooling can include IPA Extensions and Spacing Modifier Letters ([`28af4189`](https://github.com/crosspoint-reader/crosspoint-reader/commit/28af4189d45516e2d08539d82c607deb91bb8b38), [`5eec70de`](https://github.com/crosspoint-reader/crosspoint-reader/commit/5eec70de362b8311df6c9489646d0a061cd0e49a)).
>
> Wi-Fi credential persistence now uses synchronized in-memory access, bounded password decoding, and length/CRC integrity metadata while transparently upgrading compatible legacy JSON ([`c507e544`](https://github.com/crosspoint-reader/crosspoint-reader/commit/c507e544)).
>
> Justified Ruby/CJK layout now reserves annotation overhang at both line edges and favors longer equal-cost lines; streamed File Browser/OPDS responses yield and feed the watchdog; and TXT navigation reaches the end-of-book sentinel through the shared skip path ([`046827fc`](https://github.com/crosspoint-reader/crosspoint-reader/commit/046827fc), [`ba1b849f`](https://github.com/crosspoint-reader/crosspoint-reader/commit/ba1b849f), [`63fcbab0`](https://github.com/crosspoint-reader/crosspoint-reader/commit/63fcbab0)).
>
> EPUB page marks and text highlights now carry visible-text anchors in `BookmarkStore` v5, keeping them attached to their content after repagination; section cache v44 stores the per-page lookup table while retaining v1-v4 bookmark migration.
>
> Hyphenation now distinguishes normal spaces, zero-width continuations, visible breakable hyphens/dashes, soft hyphens, and non-breaking hyphens without breaking Focus Reading boundaries ([`25cf99b2`](https://github.com/crosspoint-reader/crosspoint-reader/commit/25cf99b2)). The EPUB section cache is bumped to v45 for the changed token layout.
>
> CJK-capable SD font families can supply size-matched 8/10/12 pt UI fallbacks. File Browser, Recent Books, and the EPUB chapter list batch-prewarm their visible strings, adapting the coverage and SD-read optimizations from [`10db60c4`](https://github.com/crosspoint-reader/crosspoint-reader/commit/10db60c4), [`6cfc55b6`](https://github.com/crosspoint-reader/crosspoint-reader/commit/6cfc55b6), and [`a0daab99`](https://github.com/crosspoint-reader/crosspoint-reader/commit/a0daab99).
>
> Reader line spacing adds `Extra wide` ([`28377310`](https://github.com/crosspoint-reader/crosspoint-reader/commit/28377310)); the web EPUB optimizer can optionally remove embedded fonts, their manifest/encryption records, and `@font-face` rules ([`d28b9390`](https://github.com/crosspoint-reader/crosspoint-reader/commit/d28b9390)). Host regression coverage now exercises BookmarkStore v1-v5 migration, anchored highlights/page marks, Ruby/CJK layout, and Unicode token boundaries.
>
> CrossInk's highlight matcher is adapted to keep marks stable across layout-inserted hyphens, split ellipses, and NBSP fragments while preserving authored hyphens; EPUB section cache v46 stores the compact inserted-hyphen marker ([`f95dfde0`](https://github.com/uxjulia/CrossInk/commit/f95dfde08bf8fc0b6d060a7d0700c32677a6f4b0), [`58843b95`](https://github.com/uxjulia/CrossInk/commit/58843b95), [`aabcb670`](https://github.com/uxjulia/CrossInk/commit/aabcb670), [`ac3f772c`](https://github.com/uxjulia/CrossInk/commit/ac3f772c)).
>
> KOReader passwords are now write-only in web settings; SD-font discovery is deferred until requested and the active font/catalog are released before Wi-Fi startup; File Browser JSON is sent in allocation-checked TCP-sized batches without `std::function` callback allocation ([`1cb17f2c`](https://github.com/uxjulia/CrossInk/commit/1cb17f2c), [`2d3afbe5`](https://github.com/uxjulia/CrossInk/commit/2d3afbe5), [`34cd593a`](https://github.com/uxjulia/CrossInk/commit/34cd593a), [`1d6b82f3`](https://github.com/uxjulia/CrossInk/commit/1d6b82f3), [`5ab4a2bb`](https://github.com/uxjulia/CrossInk/commit/5ab4a2bb)).
>
> Added `Hide File Extension`, with translations for all 23 UI languages, and made `/fonts`, `/dictionaries`, `/.sleep`, and `/sleep` resolve regardless of capitalization while preserving the exact on-card path for reads, installs, and deletion ([`e0441c63`](https://github.com/uxjulia/CrossInk/commit/e0441c63), [`b1ed6a98`](https://github.com/uxjulia/CrossInk/commit/b1ed6a98)).
>
> Follow-up hardening keeps the File Browser's 640-byte JSON workspace off the network task stack, exposes only a boolean “configured” hint for the write-only KOReader password, clears password replacements from the browser after saving, and logs the free/contiguous heap recovered by releasing SD fonts before Wi-Fi. Host regressions now also round-trip section-cache text blocks with inserted-hyphen/ruby/focus metadata and verify case-insensitive SD root discovery preserves the stored directory spelling.
